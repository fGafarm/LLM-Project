## 4. 根本原因と解決策

### 根本原因（v10）

```
Phase 1: セグメント情報QA抽出
  └─ 出力: 土木 1,092百万円、建築 1,631百万円（正しい）

Phase 2: 最終レポート生成
  └─ 入力: Phase1結果 + XBRL（全社売上 17,650億円）
  └─ 出力: 全セグメント = 17,650億円（誤り）
  └─ 原因: LLMがPhase1結果を無視し、XBRLの全社売上高で置換
```

### 解決策（v10.2）

```
Phase 1: セグメント情報QA抽出
  └─ 出力: 土木 1,092百万円、建築 1,631百万円

★ v10.2新規: 直接フォーマット
  └─ Phase1結果を直接Markdown形式に変換（LLMバイパス）
  └─ 単位変換: 百万円 → 億円

Phase 2: 最終レポート生成
  └─ セグメント部分は直接フォーマット結果で置換
```
